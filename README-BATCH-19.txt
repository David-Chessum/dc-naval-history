Batch 19 update
26 August 2026

This package contains all website changes made since the revised Batch 18 deployment package.

Changes included

1. publications.html
   - Replaced the Publications and Presentations page with the revised version using the edited abstracts.
   - Added separate links for Part 1, Part 2 and Part 3 of “The Washington Naval Conference, 1922” published in The Chough.

2. warship-export-case-studies.html
   - Corrected “Sanjuro” to “Sanjurjo”.
   - Standardised Status entries from “unknown” to “Unknown”.
   - Changed the Ship Type filter from a drop-down list to a text-entry filter.
   - Corrected the Ship Type filter so that results update as each character is typed.
   - Ship Type filtering is case-insensitive and accepts partial matches rather than requiring an exact match.

3. warships-for-spain.html
   - Corrected “General Sanjuro” to “General Sanjurjo”.

Deployment
Upload the three HTML files in this package to the site root, replacing the existing files of the same names.
