The Preserved Warships table has been corrected and expanded. The PKM-357 replica and Welman records have been corrected, the Marinemuseet website link has been added, and eleven additional preserved craft have been inserted in the appropriate vessel-type sections.

Deploy all files in this ZIP to the website root, replacing files with matching names. The superseded search-index-comprehensive-v26.js may be removed after deployment if it is no longer referenced.
