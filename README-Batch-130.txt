Batch 130 - 7 November 2026

Deployment instructions
1. Back up the matching files currently on the server.
2. Upload all ten HTML and JavaScript files in this ZIP to the website root, replacing matching filenames. Do not upload this README as a web page.
3. Retain existing website files and assets not included in this package. This is an incremental deployment, not a complete website backup.
4. Refresh the home page and Search using Ctrl+F5. Check the new article link from the home page, What's New and Warship Export Case Studies.
5. Check Search for British Destroyers for Mexico, Washington Herald, ADM 234/131 and Australian Defence Force Academy.
